# SpotiDAW Music Player

Este proyecto es un **reproductor de música** desarrollado con las siguientes tecnologías:

* **Angular 20.3.2**
* **TypeScript**
* **HTML5**
* **CSS3**
* **Bootstrap 5.3.8**
* **Zoneless + Estrategia de detección de cambios OnPush** para optimizar el rendimiento

---

## 🚀 Funcionalidades

* **Subir canciones locales** o subidas en internet.
* **Reproducción de audio** directamente en el navegador utilizando HTML5 Audio.
* **Búsqueda por título o artista**.
* **Gestión de favoritos**, almacenada en **LocalStorage**.
* **Persistencia local** de todas las canciones cargadas.
* Arquitectura optimizada usando **OnPush** y **zoneless** para minimizar el trabajo de cambio de detección.

---

## 📂 Instalación

Sigue estos pasos para ejecutar el proyecto en tu entorno local.

### 1️⃣ Clonar el repositorio

```bash
 git clone <url-del-repositorio>
 cd nombre-del-proyecto
```

### 2️⃣ Instalar dependencias

```bash
 npm install
```

### 3️⃣ Ejecutar el servidor de desarrollo

```bash
 ng serve
```

Luego abre tu navegador en:

```
http://localhost:4200
```
